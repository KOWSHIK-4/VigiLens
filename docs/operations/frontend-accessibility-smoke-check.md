# Frontend Accessibility Smoke Checks

## Goal
Perform a basic accessibility review of important VigiLens frontend workflows.

## Keyboard use
- Navigate primary navigation and key controls without a mouse.
- Confirm focus is visible and follows a logical order.
- Verify dialogs and menus can be opened and closed by keyboard.
- Check that focus is not lost behind an open modal.

## Content and controls
- Confirm form fields have understandable labels.
- Check that buttons and icon-only controls have accessible names.
- Verify status and severity are not communicated by color alone.
- Confirm validation errors are associated with the relevant fields.
- Review text contrast and zoom behavior on key screens.

## Dynamic updates
- Check whether important alert and camera status changes are announced or otherwise discoverable.
- Ensure frequent updates do not make the interface unusable for assistive technology.

## Record
List the pages tested, browser and assistive technology where used, findings, and remediation items. This smoke check is not a substitute for a full accessibility audit or formal conformance assessment.
